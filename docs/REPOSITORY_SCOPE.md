# Public repository scope

This repository is intentionally **not** the MapleMCP implementation repository.

## Public here

- product documentation
- architecture/trust-boundary documentation
- MCP tool/capability documentation
- installation and release information
- changelog/provenance
- security-reporting policy
- Issues, Discussions, and public community material
- selected user-facing release artifacts

## Private

- endpoint/runtime implementation
- Worker Fabric implementation
- browser implementation
- hosted control-plane implementation
- production deployment configuration and topology
- signing and rollout operations
- internal incident/operator runbooks
- private acceptance evidence
- unrelated managed-service product internals
- internal engineering coordination and commercial planning

This boundary is deliberate and comparable to many commercial remote-control/agent products: public interfaces, security expectations, documentation and community channels; proprietary product implementation.
