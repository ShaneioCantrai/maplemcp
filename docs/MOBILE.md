# Mobile support

MapleMCP treats mobile devices as a separate enrolled device class.

The 0.2.28 public MCP contract contains 12 mobile capabilities covering device information, app launch, URI opening, media controls, notification listing, accessibility-tree inspection, screenshots, taps, scrolls, global navigation actions, text entry, and bounded gestures.

Mobile UI control depends on operating-system permissions and the device's advertised capability policy.

This repository documents the public mobile capability contract; the product implementation is not published here.
