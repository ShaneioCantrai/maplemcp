# Contributing

MapleMCP's implementation is not developed in this public repository, but community contributions are welcome.

Useful contributions include:

- reproducible bug reports
- feature requests and use cases
- documentation corrections
- interoperability feedback
- accessibility/usability feedback
- security reports through the private security channel
- questions and technical discussion

Documentation pull requests may be accepted. Product implementation pull requests cannot be accepted here because the implementation repository is private.

## Bug reports

Include:

1. MapleMCP version
2. platform
3. expected behavior
4. observed behavior
5. minimal reproduction steps
6. safely redacted logs/evidence when useful

Do not publish credentials, private infrastructure, or vulnerability details.

## Security

Follow [SECURITY.md](SECURITY.md). Vulnerabilities must not be disclosed through public Issues or pull requests.
